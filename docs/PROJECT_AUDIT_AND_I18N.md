# Аудит чата и план международной локализации

Дата ревизии: октябрь 2026. Аудит по содержимому ключевых файлов репозитория, без запуска сервера.

## Что найдено в GitHub
- Telegram polling: колесо баланса, оценки и история, действия, отчёт, рефлексия, подходы, профориентация, возрастные настройки.
- Родительское психообразование: возрастные переходы, семейные конфликты, цифровые привычки, творчество, безопасность, когнитивная безопасность.
- Индекс SQLite: `parenting_index.py`, поиск по ключам и маркерам.
- Языковые настройки: `language_preferences.py`, хранение `ru/en`, английские краткие тексты родительских тем.
- Документы: политика возрастной безопасности, родительские цифровые привычки, архитектура возрастной базы знаний, научное ядро, когнитивная безопасность.

## Что не завершено
1. Полный перевод интерфейса, сценариев, кризисных ответов и справочника на английский.
2. Проверка научных утверждений с конкретными URL, версиями и датами рецензирования.
3. Таблицы `scientific_claims` и `topic_claims` с правами только на чтение для ИИ.
4. Полнотекстовый поиск по-русски и по-английски; сейчас индекс упрощённый.
5. Настоящая проверка возрастных ограничений и тестирование с участием специалистов.
6. PDF-отчёты, полноценный OpenAI-адаптер, развертывание на сервере, end-to-end тесты.
7. Профессиональная психометрическая профориентация и связь с подтверждёнными навыками.

## Ранее не сохранённое уточнение
Смысл обсуждения ненормативной лексики: ребёнок может подражать речи родителей, повторять грубые слова вне контекста и сталкиваться с конфликтами с детьми и взрослыми. Это вероятный социальный механизм, а не доказательство повреждения интеллекта отдельными словами. Требуется добавить в материал о когнитивной безопасности при следующем обновлении.

## Локализация
- Русский: основной интерфейс и содержательные сценарии.
- Английский: команды выбора языка и краткие родительские карточки. Остальные разделы пока на русском.
- В будущем: единый словарь ключей, локализованные кнопки и ответы, адаптация кризисных маршрутов по стране пользователя (без вывода страны из языка), региональные источники.
- Язык выбирает сам пользователь; отсутствие русскоязычности не должно ограничивать доступ к образовательным материалам.

## Критерий готовности
Не считать процент субъективной готовности доказательством работоспособности. До запуска: CI, `pytest`, синтаксическая проверка, тестирование Bot API, удаление данных, конфиденциальность, возрастные ограничения и проверка контента.
