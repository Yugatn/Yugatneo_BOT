# Управление пошаговым коучингом

Пользователь запускает добровольную сессию командой `/coaching_session`
(или кнопкой «🧭 Коучинг по шагам») и отдельно подтверждает согласие.

- `/skip` — пропустить текущий вопрос без записи фиктивного ответа.
- `/repeat` — повторить вопрос, сохранив этап.
- `/progress` — показать номер текущего вопроса без раскрытия ответов.
- `/cancel` — завершить сессию и очистить временные ответы.

Пять этапов: цель, факты/предположения, варианты, действие и проверка.
Если вопросы пропущены, бот не утверждает, что сформирован полный план.

Сессия остаётся исключительно в памяти процесса и автоматически не
сохраняется в SQLite. После перезапуска бота незавершённая сессия теряется.
Кризисные сообщения должны обрабатываться до механизма коучинговых шагов;
изменения в данном PR не затрагивают кризисный маршрутизатор, удаление данных
или защиту отправки Telegram.

## Проверки

`python -m pytest -q tests/test_coaching_session.py tests/test_coaching_session_controls.py`

Полную регрессию и автономную приёмку запускать в CI перед объединением:
`python -m pytest -q`, `python -m app.services.offline_acceptance`.
