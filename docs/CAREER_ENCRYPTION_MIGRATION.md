# Миграция профориентации

Команда переводит старые поля `interest`, `skill`, `next_experiment` таблицы `career_reflection` в зашифрованный формат Fernet. Содержимое ответов не выводится в консоль.

Перед выполнением **остановите Telegram-бота**, создайте зашифрованную резервную копию SQLite и проверьте восстановление. Установите `YUGATNEO_DATA_ENCRYPTION_KEY` через менеджер секретов сервера.

Предварительная проверка без изменений:

`python -m app.services.migrate_career_encryption --db /secure/path/yugatneo_bot.sqlite3`

Применение после проверки:

`python -m app.services.migrate_career_encryption --db /secure/path/yugatneo_bot.sqlite3 --apply`

Миграция транзакционная и повторяемая; уже зашифрованные поля пропускаются с проверкой ключа. **Оценки колеса баланса, его история, действия и другие персональные таблицы пока не шифруются этим инструментом.** Старые копии базы не очищаются автоматически. В production требуется отдельный аудит хранения и восстановления.
