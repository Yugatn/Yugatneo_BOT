# Ветвящийся диалог: «если — то»

Реализован автономный сценарий в `app/services/branching_dialogue.py`.

Пользователь запускает кнопку «🌿 Диалог по ответам» или `/branch`, выбирает ответ, и бот переходит к следующему узлу. Переход задаётся явно и не требует платного ИИ.

## Пример

- Если пользователь выбрал «Эмоции и состояние», следующий вопрос — о текущем состоянии.
- Если затем выбрал «Тревога», следующий вопрос отделяет известное от предполагаемого.
- Если выбрал «Усталость», вопрос касается нагрузки и доступного отдыха.
- Если выбрал «Цель и действие» → «Трудно начать», вопрос помогает определить маленький безопасный шаг.

## Архитектура

- `BranchNode.prompt`: вопрос человеку.
- `BranchNode.choices`: пары (надпись кнопки, идентификатор следующего узла).
- `advance(node, answer)`: выбирает ветку **только по явному ответу**, не угадывает психологический профиль.
- `question_context(node)`: подсказка для **будущей** интеграции с ИИ, с ограничением на диагностические выводы. Пока **не передаётся автоматически** в LLM.
- В таблице `bot_state` хранится только текущий узел (`branch:<id>`), не полный текст ответов.

## Следующие этапы

1. Добавить визуальное редактирование дерева (например, через авторскую таблицу с колонками `node_id, prompt, option_label, target_node_id, risk_level`) и проверки циклов.
2. Добавить явный переход по согласию пользователя из автономного сценария в ИИ-диалог, передав только идентификатор выбранной ветки и минимальный контекст.
3. Для свободного текста — спрашивать уточнение, а не автоматически классифицировать человека по ключевым словам.
4. Отдельно тестировать защиту от кризисных ситуаций и непреднамеренного применения психологически чувствительных вопросов.

Сценарий — инструмент саморефлексии, **не диагностический тест**. Пользователь всегда может прекратить участие через `/cancel`.
