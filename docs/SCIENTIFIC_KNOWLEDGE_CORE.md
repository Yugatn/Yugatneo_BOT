# Научное ядро и редакционная целостность Yugatneo_BOT

## Принцип
ИИ использует утверждённые записи как проверяемые ориентиры, а не изменяет их по собственному усмотрению. Ни один тезис не объявляется непогрешимым: научные выводы пересматриваются при появлении качественных новых данных.

## Структура записи
`fact_id`, `claim`, `scope`, `evidence_level`, `source_urls`, `locale`, `region`, `reviewed_at`, `version`, `status`, `limitations`.

- `claim`: аккуратное утверждение с оговорками, без универсализации.
- `evidence_level`: тип основания (систематический обзор, рекомендации организации, теория, гипотеза).
- `source_urls`: прямые проверяемые ссылки, добавляются после редакционной проверки.
- `status`: draft / reviewed / superseded. Только `reviewed` используется для уверенных формулировок.
- `limitations`: область применимости и ограничения.
- `version`: история изменений; обновление утверждений только через проверяемый коммит.

## Правила ответа ИИ
1. Извлекать лишь относящиеся к вопросу записи из локального индекса.
2. Отделять научный консенсус, теоретическую интерпретацию и авторские предложения.
3. Не изобретать ссылки, диагнозы и причинные связи.
4. При конфликте источников явно обозначать неопределённость и не выдавать ответ как окончательный.
5. Не передавать в стороннюю модель персональные сведения о ребёнке без отдельного информированного согласия и правового основания.
6. Для сообщений о насилии сначала обеспечивать безопасную маршрутизацию к человеческой помощи, не предлагать парную терапию как универсальное решение.

## Образовательные ядра
- Ребёнок может учиться через наблюдение, совместную деятельность и постепенное освоение самостоятельных действий.
- Зона ближайшего развития — теоретическая концепция Л. С. Выготского о задачах, решаемых с помощью более компетентного партнёра.
- Интериоризация описывает переход социально опосредованных действий и способов мышления во внутренний план.
- Родитель может поддерживать творчество, не будучи профессионалом в соответствующей области.
- Насилие и унижение не являются необходимыми инструментами воспитания.
- Насилие возможно независимо от пола агрессора; помощь ориентирована на безопасность пострадавшего.
- Ребёнок не обязан демонстрировать определённый творческий результат; поддержка не гарантирует конкретную профессию или уровень способностей.

## Технический план
На текущем этапе знания хранятся в версионируемом `parenting_knowledge.py` и копируются в SQLite через `parenting_index.py`. Следующий этап — отдельная таблица `scientific_claims` и связи `topic_claims` с URL, датами ревизии и утверждённым статусом. ИИ должен иметь доступ только на чтение к утверждённым фактам. Пользовательские сообщения не могут изменять их.

Это архитектурная спецификация, не заявление о готовом механизме проверки источников.
