# Каталог вопросов

Полный каталог находится в `data/questions.ru.json`. Начальная версия содержит 210 вопросов по 21 направлению: текущая ситуация, эмоции, убеждения, стресс, самоотношение, ценности, отношения, границы, тревога, изменения и утрата, бережная рефлексия чувствительных тем, цели, решения, привычки, работа, творчество, ресурсы, самосострадание, конфликты, повседневная устойчивость и закрепление изменений.

## Принципы
- Вопросы открытые и нейтральные, не предполагают заранее известного ответа.
- Это библиотека вариантов, а не опросник, который человек обязан пройти целиком.
- Бот задаёт по одному вопросу и подбирает следующий с учётом запроса, ответа, согласия и контекста.
- Вопросы о травматическом опыте не должны форсировать воспоминания или подробное описание событий.
- Вопросы не являются диагностическими критериями и не заменяют работу со специалистом.
- Для каждого элемента хранятся стабильный ID, категория, подкатегория, формулировка, цель, теги и уровень чувствительности.
- Перед релизом нужно провести редакторскую, этическую и пользовательскую проверку.
