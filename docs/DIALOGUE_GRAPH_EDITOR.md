# Редактирование сценариев «если — то»

Все узлы базового сценария Yugatneo BOT расположены в `data/dialogue_graph.ru.json`. Это первый шаг к визуальному редактору: файл можно открывать через интерфейс GitHub («Edit this file») без командной строки.

## Структура

- `start`: ID первого узла.
- `nodes[].id`: устойчивый уникальный ID.
- `nodes[].prompt`: один понятный вопрос человеку.
- `nodes[].choices`: список пар [«надпись кнопки», «ID следующего узла»].
- `nodes[].followup`: идентификатор темы из каталога `data/questions.ru.json` или `data/questions.extended.ru.json`.

Если `choices` пустой — узел завершает маршрут. На конечном узле бот предлагает самостоятельное осмысление, вопрос из банка (когда тема доступна) или **добровольное** продолжение с подключённым ИИ.

## Пример

```json
{
  "id": "confidence",
  "prompt": "Что сейчас больше всего затрудняет действие?",
  "choices": [
    ["Сомневаюсь в себе", "self_assessment"],
    ["Не понимаю первый шаг", "first_step"]
  ]
}
```

Каждая целевая вершина должна существовать. В текущем редакторском формате циклы намеренно запрещены. Все узлы должны быть достижимы из стартового. Повторяющиеся ID и одинаковые подписи вариантов в одном узле запрещены.

## Ответственная редактура

Перед внесением вопросов по травматическому опыту, тяжёлым психическим состояниям, психоаналитическим интерпретациям, детским переживаниям или хроническим заболеваниям нужна отдельная проверка допустимости автономного использования. Не добавляйте советы менять лечение, внушающие интерпретации, категоричные психологические ярлыки и давление на раскрытие личной информации.

Возраст, гендер, инвалидность и диагноз нельзя использовать как автоматические выводы о личности. Специфические маршруты лучше запускать после добровольного выбора пользователя и пояснения цели.

## Проверка

Функция `load_graph()` в `app/services/branching_dialogue.py` проверяет схему, переходы, циклы и достижимость. Тесты: `tests/test_dialogue_graph_editor.py`. Изменения сохранены в GitHub, но выполнение тестов и развёртывание бота требуется подтвердить отдельно.
