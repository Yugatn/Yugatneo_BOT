# Yugatneo BOT

Мультиплатформенный ИИ-помощник для коучинга, психологической рефлексии и психообразования.

> **Границы продукта.** Бот не ставит диагнозы, не заменяет психотерапевта или экстренную помощь и не обещает лечение. До запуска нужны клиническая/этическая проверка сценариев, политика конфиденциальности и проверка применимого законодательства.

## Цели

- Единое ядро диалога, не привязанное к конкретной языковой модели.
- Каталог коучинговых и рефлексивных вопросов с темами, тегами и подсказками по применению.
- Первые 7 вопросов каталога доступны бесплатно; дальнейший доступ открывается активной подпиской.
- Адаптеры каналов: Telegram, Instagram Direct и WhatsApp. MAX — отдельный последующий адаптер после подтверждения доступа к официальному API.
- Безопасная замена провайдера модели: сейчас mock-движок, позднее OpenAI или другой совместимый провайдер.
- Сначала минимальный бюджет: локальная разработка и бесплатные квоты/тарифы там, где они доступны. Бесплатный круглосуточный хостинг и бесплатные запросы к модели не гарантируются.

## Статус

Это стартовый каркас с каталогом из **210 вопросов в 21 тематическом направлении**, базовой проверкой лимита и тестами. Он не является уже запущенным ботом: для реальных сообщений понадобятся токены каналов, публичный HTTPS webhook, хранилище, выбранная модель и настройки оплаты. Платёжная интеграция пока не включена.

## Правило бесплатного доступа

MVP трактует «первые 7 вопросов» как **первые семь вопросов каталога, выданных конкретному пользователю**. Счётчик ведётся на сервере и общий для каналов, если аккаунты каналов связаны. Входящие сообщения пользователя сами по себе не считаются вопросами каталога. После лимита бот предлагает подписку. Статус оплаты проверяется сервером; кнопка/сообщение пользователя не может самостоятельно активировать подписку.

- До настройки платежей подписка может быть выдана только вручную в тестовом режиме.
- Кризисная информация, сообщение о границах бота и возможность обратиться за помощью не блокируются платной стеной.
- Нужно определить правила отмены, возвратов, период подписки и обработку вебхуков до запуска платёжного провайдера.

## Быстрый старт

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload
```

Пока Telegram/Meta credentials не заданы, приложение запускается в режиме разработки и не принимает реальные сообщения платформ. Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/SAFETY.md](docs/SAFETY.md), [docs/CHANNELS.md](docs/CHANNELS.md).

## Структура

- `app/core/` — конфигурация, модели данных, правила доступа.
- `app/services/` — диалог, каталог вопросов, подписки, безопасность.
- `app/llm/` — интерфейс модели и mock/OpenAI-провайдеры.
- `app/channels/` — платформенные адаптеры.
- `data/questions.ru.json` — версионируемый каталог вопросов.
- `tests/` — тесты доступа, лимита и безопасности.
- `docs/` — архитектура, запуск, безопасность и подключение каналов.

## Принципы

1. Не хранить токены в Git; использовать переменные окружения/секреты хостинга.
2. Не отправлять личные данные в модель без необходимости и информирования пользователя.
3. Не использовать один и тот же идентификатор пользователя между каналами без явного связывания аккаунтов.
4. Не выдавать предположения модели за диагнозы или достоверные факты.
5. Не запускать платежи и обработку чувствительных данных до проверки безопасности и правовых требований.
