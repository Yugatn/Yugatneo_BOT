# Матрица вопросов: источник, редактор и автономный режим

## Решение
- Канонический каталог: `data/questions.ru.json` в GitHub; 310 вопросов в 31 тематической категории на момент обновления.
- Рантайм: `app/services/question_catalog.py` читает локальный снапшот, проверяет ID, обязательные поля и число вопросов. Для автономного режима используются только вопросы `risk_level=standard`.
- Telegram MVP: `📚 Вопросы` или `/questions`, выбор категории её техническим идентификатором, вопросы по очереди, `/skip` и `/cancel`. Ответы в этом режиме **не хранятся**; пользователь самостоятельно выбирает следующий шаг. Это не индивидуализированная терапия.
- OpenAI или другая LLM необязательны для каталога: при отключении модели сохраняется возможность проходить вопросы.
- Отдельный разговорный ИИ подключается как опциональный модуль, не вправе обходить safety gate или выдавать неподтверждённые психологические заключения.

## Google Sheets (редактор на позднем этапе)
Таблица — **редактор для автора**, а не хранилище ответов пользователей и не зависимость ответа бота от доступности Google.
Предлагаемые столбцы: `id, category, subcategory, text, purpose, tags, risk_level, status, reviewer, methodology, last_reviewed`.
Путь публикации: Google Sheets → ручной экспорт CSV → валидация и проверка дубликатов → review в GitHub → JSON-каталог → deployment.
Никакой прямой публикации таблицы в production без контроля качества. Ни в какую публичную таблицу не попадают Telegram ID, ответы, сведения о здоровье.

## Следующие этапы
1. Проверить CI, зависимости, поведение команд и использование терминов категорий; добавить русскоязычный выбор направления.
2. Добавить валидацию данных редактора, скрипт импорта CSV, статус review и версионирование.
3. Отдельный режим guided reflection с явным согласием, сохранением минимального прогресса и кнопкой удаления.
4. Подключить модель с ограничением расходов и надёжным fallback; тестировать кризисные сценарии и отсутствие диагноза.
5. Облачный запуск 24/7 только после настройки секретов, политики хранения, контроля доступа и мониторинга.
6. Опционально Google Sheets API с отдельным service account и минимальными правами — без хранения ключей в репозитории.

## Статус
Файлы и маршруты добавлены в исходники GitHub. Работа Telegram, CI и облачный деплой в этом изменении не проверены. Разговорная модель зависит от конфигурации провайдера.
