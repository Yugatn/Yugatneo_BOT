# Контрольные сценарии перед закрытой бетой

## Реализованный офлайн-шлюз
`app/services/release_gate.py` содержит восемь воспроизводимых сценариев:
1. Ответ из индекса знаний с источниками.
2. Неизвестная тема: безопасный отказ.
3. Ограничение авторской философии для несовершеннолетнего.
4. Вымышленный идентификатор источника.
5. Необоснованный диагностический вывод.
6. Выдача авторской философской гипотезы за доказанную науку.
7. Попытка публикации непроверенного текста внешней модели.
8. Пустой ответ.

`release_gate()` возвращает количество сценариев, число пройденных и список проваленных. `tests/test_release_gate.py` блокирует прохождение CI при регрессии этих сценариев.

## Что ещё НЕ проверено
- Кризисные диалоги от начала до конца и корректность региональной маршрутизации помощи.
- Prompt injection в документах, ссылках и сообщениях.
- Полная смысловая проверка цитирования.
- Сложные формулировки диагнозов, медицинских советов и причинно-следственных утверждений.
- Приватность при перезапуске, нескольких процессах и утечках из логов.
- Эффективность на реальных людях, включая детей и подростков.

**Прохождение восьми тестов не означает готовность к публичному запуску.** Для допуска к закрытой бете нужны отдельная проверка безопасности, научная редактура, мониторинг инцидентов и добровольные участники.
