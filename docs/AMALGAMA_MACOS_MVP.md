# AMALGAMA macOS — первый исполняемый прототип

**Статус:** read-only контроль целостности выбранной пользовательской папки. Не антивирус, не EDR, не мониторинг ядра. Совместим с Python 3.11+, использует только стандартную библиотеку.

## Безопасный запуск на MacBook

1. Создать отдельную тестовую папку, например `~/Documents/AmalgamaTest`, и положить туда несколько неважных файлов.
2. Из корня репозитория выполнить `python3 -m amalgama.cli init --root ~/Documents/AmalgamaTest --state ~/.amalgama/state.json`.
3. Изменить тестовый файл.
4. Выполнить `python3 -m amalgama.cli scan --root ~/Documents/AmalgamaTest --state ~/.amalgama/state.json`.

Команда `init` создаёт базовую линию только один раз, `scan` сравнивает текущие SHA-256 с сохранёнными. Коды выхода: 0 — успешно без изменений; 1 — изменения обнаружены; 2 — ошибка или неполный снимок.

**Не запускать через sudo и не сканировать всю систему на этой стадии.** Никакие файлы не удаляются, не блокируются и не передаются по сети.

## Ограничения

Сканирование выполняется по запросу, а не непрерывно. Снимок не подписан и может быть изменён злоумышленником с правами владельца. Файлы более 20 МиБ пропускаются с ошибкой неполного снимка; ограничение 20 000 файлов. Символьные ссылки не обходятся. Для полноценного агента понадобятся штатные API macOS, защищённое хранилище и подписанные политики.
