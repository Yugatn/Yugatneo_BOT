# AMALGAMA: периодический наблюдатель

Это экспериментальный локальный мониторинг целостности, а не антивирус. Он не меняет пользовательские файлы, не использует sudo, не блокирует процессы и не отправляет данные в сеть.

Сначала создать базовую линию в отдельной тестовой папке:

```sh
python3 -m amalgama.cli init --root ~/Documents/AmalgamaTest --state ~/.amalgama/state.json
```

Запустить наблюдение каждые 10 секунд:

```sh
python3 -m amalgama.watch --root ~/Documents/AmalgamaTest --state ~/.amalgama/state.json --interval 10
```

Для ограниченного теста добавить `--iterations 3`. Остановка: Ctrl+C. Выводятся только изменения путей, а не содержимое файлов. **Возможны пропуски изменений между опросами**, поэтому это не событийный сенсор macOS. Неполные сканирования не заменяют предыдущий снимок.

Проверки: `python3 -m pytest tests/test_amalgama_cli.py tests/test_amalgama_watch.py`.

Дальше: FSEvents/Endpoint Security в соответствии с поддерживаемыми Apple API, защищённый журнал, подписи базовой линии, отдельный агент объяснения и тесты отказоустойчивости. Для объединения с Symbiot и Messenger потребуется согласованная модель авторизации и отдельные разрешения на доступ к диагностике.
