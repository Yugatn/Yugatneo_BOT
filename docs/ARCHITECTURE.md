# Архитектура

## Слои

1. **Каналы** принимают вебхуки и приводят события к общей модели.
2. **Application services** выполняют проверку доступа, безопасность, диалог и маршрутизацию.
3. **Каталог вопросов** хранит редакционно проверенные вопросы и метаданные.
4. **LLM provider** реализует общий интерфейс; провайдер заменяется конфигурацией.
5. **Хранилище** хранит внутренний ID пользователя, связи аккаунтов, историю согласий, использование бесплатных вопросов и подписки.
6. **Платёжный адаптер** подтверждает оплату только по проверенному серверному webhook.

## Идентичность

Ключ пользователя канала — пара `(channel, external_user_id)`. Нельзя автоматически считать одинаковые имена/телефоны в разных сервисах одним человеком. Объединение профилей выполняется только через явный безопасный процесс связывания.

## Доступ к каталогу

`FREE_QUESTION_LIMIT=7`. Проверка должна выполняться на сервере перед выдачей следующего вопроса каталога. Счётчик увеличивается транзакционно только после успешной выдачи. Одновременные запросы должны блокироваться/обрабатываться транзакционно, чтобы пользователь не получил больше лимита из-за гонки.

Предлагаемая модель: семь первых вопросов каталога бесплатны для внутреннего пользователя; затем требуется активная подписка. Обычные сообщения и ответы пользователя не следует ошибочно считать вопросами каталога. Если продуктовая модель изменится, это должно быть изменением правила доступа, а не копиями логики в каждом адаптере.

## Подписка

Хранить минимум: provider, provider_subscription_id, status, started_at, expires_at, updated_at. Состояния: inactive, active, past_due, canceled, expired, trial. Подписка активна только при серверно подтверждённом статусе и неистёкшем сроке. До выбора провайдера оплаты реальная подписка не реализована.

## Хранение

Для прототипа допустим SQLite; для публичной эксплуатации предпочтительнее PostgreSQL. Добавить миграции, резервные копии, срок хранения, удаление данных по запросу и ограничение доступа. Не сохранять разговоры без понятной цели и согласия.
